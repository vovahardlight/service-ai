# Custom Tools landing page

Next.js landing page for custom software, AI tools, and workflow automation.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

The contact section has direct WhatsApp and email buttons. Set `NEXT_PUBLIC_WHATSAPP_NUMBER` to the international phone number using digits only (for example `34600111222`), and set `NEXT_PUBLIC_CONTACT_EMAIL` to the public contact address. WhatsApp opens a direct chat and email opens the visitor's mail app.

Set `NEXT_PUBLIC_SITE_URL` to the real public origin to publish absolute sitemap URLs and canonical metadata. Replace `[Company Name]`, direct contact links, and the draft legal details in the content/pages before launch. The project list intentionally identifies the initial demo as in development and does not claim unverified client work.
